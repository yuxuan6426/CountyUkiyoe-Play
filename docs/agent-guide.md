# 县城浮世绘 · 领卡处智能体指南

按照玩家复制的提示词观察指定对象，在八张候选卡里选最接近其办事方式的一张。[八张角色及特征代码](../public/roles.json)由领卡仓库维护。需要理解角色时，可按需查看[主图鉴的人物档案](https://github.com/yuxuan6426/CountyUkiyoe/tree/main/gallery/characters)，通过角色目录里的 `slug` 定位目录。档案描述的是虚构人物与社会群像，个人匹配依据来自玩家本次授权范围内可观察的行为。

## 取材

从当前对话开始。可以参考已有权限只读的记忆、历史对话和当前项目近期任务，任务优先看近 30 天，合计至多 20 条记录。区分用户的实际做法、AI 的实际做法和双方提议或假设的事。输出概括后的匿名行为，省去可识别信息。材料打不开时，使用复制提示词里已有的候选表。

## 回执

返回一个 JSON 对象，可以放进单个 JSON 代码围栏。

| 字段 | 填写规则 |
| --- | --- |
| `schema` 与 `v` | `"county-card"` 和数字 `2` |
| `mode` | 按提示词填写 `human`（观察用户）或 `ai`（观察 AI） |
| `scope` | `current` 只看当前对话，`history` 实际参考了其他已授权记录，`unspecified` 范围无法确定 |
| `status` | `matched` 有肯定依据，`insufficient_evidence` 缺少观察依据 |
| `role_id` | 主卡的四位编号字符串，线索不足时填 `null` |
| `traits` | 按贴合度排序的 1–3 项特征代码，首项对应主卡，线索不足时填 `[]` |
| `report.why` | 用实际观察解释主卡对应关系，线索不足时填空字符串 |
| `report.patterns` | 1–3 条匿名办事表现，线索不足时填 `[]` |
| `report.limits` | 署明覆盖的场合与判断边界，线索不足时说明还缺少哪类观察 |

把回执交给玩家，由玩家复制到提示词末尾的领卡地址。
