# 县城浮世绘 · 领卡处智能体指南

按照玩家复制的提示词观察指定对象，根据能核实的办事行为选择一张最贴近的卡。先在[完整候选目录](https://card.yuxuan.wiki/matching-catalog.json)按摘要筛选，再用目录的 `dossier_url` 打开[人物图鉴](https://xian.yuxuan.wiki/)里的对应人物。需要直接读取档案正文时用同目录的 `evidence_url`。无法联网时可使用提示词里的 100 张离线候选。用四位编号区分同名角色。

## 取材

从当前对话开始。可以参考已有权限只读的记忆、历史对话和当前项目近期任务，任务优先看近 30 天，合计至多 20 条记录。区分用户的实际做法、AI 的实际做法和双方提议或假设的事。选择角色时比较行动、处事顺序和情境。档案中的身份、年龄、性别、外貌和收入只用于理解角色背景。用匿名概括向玩家解释匹配结果。

## 回执

返回一个 JSON 对象，可以放进单个 JSON 代码围栏。

| 字段 | 填写规则 |
| --- | --- |
| `schema` 与 `v` | `"county-card"` 和数字 `3` |
| `mode` | 按提示词填写 `human`（观察用户）或 `ai`（观察 AI） |
| `scope` | `current` 只看当前对话，`history` 实际参考了其他已授权记录，`unspecified` 范围无法确定 |
| `status` | `matched` 有可观察的匹配依据，`insufficient_evidence` 缺少观察依据 |
| `role_id` | 候选的四位编号字符串，线索不足时填 `null` |
| `report.why` | 用实际观察解释主卡对应关系，线索不足时填空字符串 |
| `report.patterns` | 1–3 条匿名办事表现，线索不足时填 `[]` |
| `report.limits` | 署明覆盖的场合与判断边界，线索不足时说明还缺少哪类观察 |

把回执交给玩家，由玩家复制到提示词末尾的领卡地址。网页也兼容此前发出的 V1 和 V2 回执。
